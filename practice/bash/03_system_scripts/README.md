# Системные Bash-скрипты

Набор по методичке `bash_practice.md`. Логика и имена переменных переписаны,
добавлены проверки аргументов и запасные варианты команд.

## Файлы и каталоги

| Скрипт | Назначение |
|---|---|
| `fileinfo.sh` | сведения о файле/каталоге |
| `filecreate.sh` | создание файла (пустой / текст / дата) |
| `copybackup.sh` | копирование с бэкапом |
| `filefind.sh` | поиск файлов по фрагменту имени |
| `filepermissions.sh` | просмотр и изменение прав |

## Сеть

| Скрипт | Назначение |
|---|---|
| `myip.sh` | локальные и внешний IP |
| `pingtest.sh` | проверка доступности узла |
| `portscan.sh` | список слушающих портов |
| `download.sh` | загрузка файла (curl/wget) |
| `netstat.sh` | активные соединения |
| `dnslookup.sh` | DNS-записи домена |
| `speedtest.sh` | задержка и скорость загрузки |

## Утилиты

| Скрипт | Назначение |
|---|---|
| `counter.sh` | счётчик 1..N |
| `watcher.sh` | `tail -F` по файлу |
| `menu.sh` | интерактивное меню |

## Запуск

```bash
chmod +x *.sh
./fileinfo.sh /etc/hosts
./pingtest.sh ya.ru
./counter.sh 5
```

Часть скриптов требует установленных `iproute2`, `curl`, `bind-utils`/`dnsutils`.
Каждый скрипт перед использованием проверяет наличие нужных утилит.
