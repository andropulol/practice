# Практика «Основы работы с Linux»

Скрипты к лабораторной `linux_fundamentals.md`.

| Скрипт | Что делает |
|---|---|
| `run_lab.sh` | последовательно выполняет все команды частей 1–4 в `~/linux_practice` и печатает результат — удобно для скриншотов |
| `myfirstscript.sh` | комплексное задание: дата, каталог, лог, проверка сети, диск |
| `system_info.sh` | дополнительное задание 3: сведения о системе |
| `project_tree.sh` | дополнительное задание 1: структура `myproject/` |
| `top_logs.sh` | дополнительное задание 2: 5 самых больших `.log`-файлов |

## Запуск

```bash
chmod +x *.sh
./run_lab.sh
./myfirstscript.sh
./system_info.sh
./project_tree.sh ~
./top_logs.sh /var/log
```

`run_lab.sh` ничего не удаляет: все файлы создаются в отдельном каталоге
`~/linux_practice`. Скрипт можно запускать повторно.
