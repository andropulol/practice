# Проверочная работа по Bash

Скрипты заданий 1–4.

| Файл | Задание |
|---|---|
| `greeting.sh` | приветствие с ФИО |
| `calculator.sh` | калькулятор (+, −, ×, ÷) |
| `check_number.sh` | знак числа из аргумента |
| `list_files.sh` | `.txt`-файлы каталога с размерами |
| `selfcheck.sh` | автоматический прогон всех четырёх заданий |

## Запуск

```bash
chmod +x *.sh

./greeting.sh
./calculator.sh
./check_number.sh -5
./list_files.sh ~/Documents
./selfcheck.sh
```

## Что учтено для дополнительных баллов

- комментарии в каждом файле;
- проверка аргументов и типа ввода;
- понятные сообщения об ошибках и аккуратный вывод.
