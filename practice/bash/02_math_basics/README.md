# Практика «Вычислительные операции в Bash»

Скрипты по методичке `practice_basics_computation.md`. Все написаны самостоятельно,
имена переменных отличаются от примеров в методичке.

| Файл | Задание |
|---|---|
| `01_hello.sh` | задание 1: имя и дата |
| `02_sum.sh` | первая сумма |
| `03_all_ops.sh` | все арифметические операции |
| `04_my_math.sh` | задание 2 |
| `05_vars.sh` | переменные и пересчёт стоимости |
| `06_counter.sh` | счётчик |
| `07_rectangle.sh` | задание 3 |
| `08_input.sh` | ввод двух чисел |
| `09_calc.sh` | задание 4: калькулятор с `%` |
| `10_discount.sh` | задание 5: скидка и предупреждение |
| `11_time.sh` | задание 6: секунды из аргумента или `read` |
| `12_sum_range.sh` | сумма от 1 до N |
| `12_factorial.sh` | задание 7: факториал |
| `13_float.sh` | площадь круга через `bc` |
| `14_average.sh` | задание 8: среднее трёх чисел |
| `hw_1.sh` … `hw_4.sh` | дополнительные задания |

## Запуск

```bash
chmod +x *.sh
./02_sum.sh
./11_time.sh 3661
./09_calc.sh
```

Скрипты `08`, `09`, `10`, `11` (без аргумента), `12*`, `13`, `14`, `hw_*` ждут ввода.

## Быстрая проверка

```bash
for file in *.sh; do bash -n "$file" && echo "OK: $file"; done
```
