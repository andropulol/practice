# Практика «Основы Bash»

Набор скриптов по методичке `practice_basics_syntax.md`.
Все скрипты написаны самостоятельно: имена переменных и структура отличаются от примеров.

| Файл | Что показывает |
|---|---|
| `01_hello.sh` | переменные, подстановка команд, переменные окружения |
| `02_variables.sh` | кавычки, readonly, арифметика `$(( ))` |
| `03_input.sh` | `read`, `read -p`, `read -s` |
| `04_conditions.sh` | `if/elif/else`, числовые и строковые проверки, `-f`, `-r` |
| `05_loops.sh` | `for`, диапазон `{1..5}`, `while`, чтение файла |
| `06_functions.sh` | функции, `local`, аргументы, коды возврата |
| `07_system_info.sh` | мониторинг системы |

## Запуск

```bash
chmod +x *.sh
./01_hello.sh
```

`03_input.sh` и `04_conditions.sh` ждут ввода с клавиатуры.

## Проверка синтаксиса без запуска

```bash
bash -n 01_hello.sh
```
