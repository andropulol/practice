## Цель работы

Научиться создавать файл базы данных SQLite и таблицу, понять, где физически
хранятся данные и зачем нужен `commit()`.

## Используемые инструменты

- Python 3.11.9
- модуль `sqlite3` из стандартной библиотеки
- СУБД SQLite (встроенная, без отдельного сервера)

## Структура проекта

```
python/01_init_db/
├── init_db.py      # создание базы и таблицы
├── inspect_db.py   # проверка структуры
└── app.db          # появляется после запуска
```

## Ход выполнения

1. Создан каталог `01_init_db`.
2. Написан скрипт `init_db.py`:
   - подключение к файлу `app.db` (файл создаётся автоматически);
   - выполнение DDL-запроса `CREATE TABLE IF NOT EXISTS tasks (...)`;
   - `commit()` — фиксация структуры на диске;
   - `close()` в блоке `finally`.
3. Таблица содержит колонки:
   - `id INTEGER PRIMARY KEY AUTOINCREMENT` — суррогатный ключ;
   - `title TEXT NOT NULL` с проверкой непустой строки;
   - `status TEXT NOT NULL DEFAULT 'new'` с ограничением `CHECK (status IN ('new','done'))`.
4. Скрипт запущен дважды — второй запуск не вызвал ошибку (идемпотентность).
5. Структура проверена скриптом `inspect_db.py` через `sqlite_master` и `PRAGMA table_info`.

## Ответы на контрольные вопросы

**1. Что произойдёт, если убрать `conn.commit()` и запустить скрипт?**
Изменения останутся в незавершённой транзакции. После `close()` SQLite откатит
её, и в файле `app.db` таблицы не будет. Скрипт при этом не упадёт: `execute()`
отработает, но результат не сохранится.

**2. Чем отличается `connection` от `cursor`? Зачем нужны оба?**
`connection` — это канал связи с файлом базы. Он управляет транзакцией
(`commit`, `rollback`) и знает, с какой базой работать. `cursor` — объект,
который выполняет конкретные SQL-запросы и хранит результат выборки.
Курсор создаётся из соединения, поэтому нужны оба.

**3. Почему `id INTEGER PRIMARY KEY` заполняется автоматически?**
В SQLite колонка `INTEGER PRIMARY KEY` является псевдонимом внутреннего
`rowid`. Если значение не передано, SQLite подставляет следующее свободное
число. Дополнительно `AUTOINCREMENT` запрещает повторно использовать
удалённые номера.

**4. Что делает `DEFAULT 'new'`?**
Если колонка `status` не указана в `INSERT`, SQLite сам подставит строку
`'new'`. Если передать значение явно (включая `NULL`), будет использовано
оно; но `NOT NULL` не даст записать `NULL`.

**5. Где физически лежат данные таблицы `tasks`?**
В файле `app.db` в каталоге проекта. Внутри файла данные хранятся
в страницах B-дерева, а описание таблицы — в системном каталоге
`sqlite_master`. Отдельного сервера и отдельного хранилища нет.
