## Цель работы

Изучить синтаксис Bash: переменные, ввод, условия, циклы, функции,
обработку ошибок и запуск скриптов в Linux.

## Что демонстрирует каждый скрипт

| Скрипт | Тема |
|---|---|
| `01_hello.sh` | переменные, `$(...)`, `$USER`, `$HOME` |
| `02_variables.sh` | кавычки, `readonly`, `$(( ))` |
| `03_input.sh` | `read`, `read -r -p`, скрытый ввод `read -rs` |
| `04_conditions.sh` | `if/elif/else`, `[[ ]]`, проверки файлов |
| `05_loops.sh` | `for`, `{1..5}`, `while`, чтение файла |
| `06_functions.sh` | функции, `local`, аргументы, коды возврата |
| `07_system_info.sh` | мониторинг системы |

## Ход выполнения

1. Все скрипты начинаются с shebang `#!/bin/bash`.
2. Права на выполнение выдаются командой `chmod +x`.
3. Запуск выполняется через `./имя.sh` или `bash имя.sh`.
4. Для проверки синтаксиса использованы `bash -n` и ShellCheck 0.10.0 —
   замечаний уровня error/warning нет.
5. Все имена переменных и структура отличаются от примеров методички.
