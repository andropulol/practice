## Цель работы

Отработать вставку, чтение, обновление и удаление данных через консольный
скрипт, не отвлекаясь на веб-интерфейс.

## Структура проекта

```
python/02_console_crud/
├── console_crud.py   # интерактивное меню + демо-режим
└── app.db            # создаётся автоматически
```

Скрипт автономный: при первом запуске сам создаёт таблицу `tasks`,
поэтому Практику №1 запускать предварительно не обязательно.

## Возможности скрипта

| Пункт меню | Операция | SQL |
|---|---|---|
| 1 | показать все задачи | `SELECT` |
| 2 | добавить задачу | `INSERT` |
| 3 | отметить выполненной | `UPDATE` |
| 4 | вернуть в работу | `UPDATE` |
| 5 | удалить задачу | `DELETE` |
| 0 | выход | — |

Дополнительно реализован режим `python console_crud.py demo`, который
прогоняет весь сценарий без ручного ввода — удобно для проверки.

## Ход выполнения

1. Написан каркас с меню и циклом `while True`.
2. Реализованы функции работы с базой: `read_tasks`, `read_one`,

## Ответы на контрольные вопросы

**1. Почему для `SELECT` не нужен `commit()`, а для `INSERT` нужен?**
`SELECT` ничего не меняет. `commit()` фиксирует изменения транзакции,
а при чтении изменений нет. `INSERT`, `UPDATE`, `DELETE` меняют данные,
и без фиксации они пропадут при закрытии соединения.

**2. Что вернёт `fetchone()`, если в таблице нет строк?**
`None`. Это удобно проверять через `if row is None`.

**3. Чем `fetchone()` отличается от `fetchall()`?**
`fetchone()` возвращает одну строку (кортеж) или `None` — используют с
`WHERE id = ?`. `fetchall()` возвращает список всех строк (возможно пустой) —
используют, когда нужен весь список.

**4. Почему `(title,)` — кортеж, а `(title)` — нет?**
Кортеж из одного элемента требует запятую. `(title)` — это просто значение
в скобках, то есть строка. Без запятой `execute()` получит строку и станет
подставлять её посимвольно.

**5. Что вернёт `rowcount` после `UPDATE`, если такого id нет?**
`0`: запрос выполнился, но ни одна строка не подошла под условие.

**6. Зачем проверять `isdigit()` перед `int()`?**
`int('abc')` выбрасывает `ValueError` и роняет программу. Проверка позволяет
вывести понятное сообщение и продолжить работу.

**7. Как параметризованные запросы защищают от SQL-инъекции?**
SQL-код и значения передаются отдельно. Драйвер сам экранирует данные,
поэтому ввод вроде `'); DROP TABLE tasks; --` сохраняется как обычный текст
и не может изменить структуру запроса.
