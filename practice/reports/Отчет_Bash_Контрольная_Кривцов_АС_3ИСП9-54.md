## Задание 1. Приветствие (5 баллов)

Скрипт спрашивает ФИО и группу и выводит приветствие.

```bash
#!/bin/bash
# Проверочная работа по Bash — задание 1.
# Запрашивает ФИО и печатает приветствие.

read -r -p "Введите ваше ФИО и группу: " full_name

    exit 1
```

## Задание 2. Калькулятор (7 баллов)

Скрипт запрашивает два числа и операцию, проверяет ввод и считает
результат. Вычисления выполняет `awk`, поэтому `bc` не требуется.

```bash
#!/bin/bash
# Проверочная работа по Bash — задание 2.
# Калькулятор: два числа и операция.
# Расчёты выполняет awk, поэтому bc не требуется.

is_number() {
    [[ "$1" =~ ^-?[0-9]+([.][0-9]+)?$ ]]
}

read -r -p "Введите первое число:  " number_a
read -r -p "Введите второе число:  " number_b
read -r -p "Введите операцию (+, -, *, /): " operator

if ! is_number "$number_a" || ! is_number "$number_b"; then
    echo "Ошибка: оба значения должны быть числами." >&2
    exit 1
fi

case "$operator" in
    +|-|\*|/) ;;
    *)
        echo "Ошибка: неизвестная операция '$operator'." >&2
        exit 1
        ;;
esac

if [ "$operator" = "/" ]; then
    if awk -v divisor="$number_b" 'BEGIN { exit !(divisor == 0) }'; then
        echo "Ошибка: деление на ноль невозможно." >&2
        exit 1
    fi
fi

result=$(awk -v x="$number_a" -v y="$number_b" -v op="$operator" 'BEGIN {
    if (op == "+")      value = x + y;
    else if (op == "-") value = x - y;
    else if (op == "*") value = x * y;
    else                value = x / y;
    printf "%.10g", value;
}')

echo "Результат: $number_a $operator $number_b = $result"
```

Результаты:

```text
$ ./calculator.sh
Введите первое число:  10
Введите второе число:  5
Введите операцию (+, -, *, /): *
Результат: 10 * 5 = 50

$ ./calculator.sh
Введите первое число:  10
Введите второе число:  4
Введите операцию (+, -, *, /): /
Результат: 10 / 4 = 2.5
```

Обработка ошибок:

```text
$ ./calculator.sh
Введите первое число:  10
Введите второе число:  0
Введите операцию (+, -, *, /): /
Ошибка: деление на ноль невозможно.

$ ./calculator.sh
Введите первое число:  abc
Введите второе число:  5
Введите операцию (+, -, *, /): +
Ошибка: оба значения должны быть числами.
```

Регулярное выражение допускает целые и дробные числа, в том числе
отрицательные. Деление на ноль проверяется отдельно до вычисления.

## Задание 3. Проверка числа (6 баллов)

Скрипт принимает число аргументом и определяет его знак. Сравнение
выполняется через `awk`, поэтому работают и целые, и дробные значения.

```bash
#!/bin/bash
# Проверочная работа по Bash — задание 3.
# Определяет знак числа, переданного аргументом.
# Сравнение через awk — работает и для целых, и для дробных.

if [ -z "$1" ]; then
    echo "Использование: $0 <число>" >&2
    exit 1
fi

value="$1"

if [[ ! "$value" =~ ^-?[0-9]+([.][0-9]+)?$ ]]; then
    echo "Ошибка: '$value' не является числом." >&2
    exit 1
fi

verdict=$(awk -v v="$value" 'BEGIN {
    if (v > 0)      print "положительным";
    else if (v < 0) print "отрицательным";
    else            print "нулём";
}')

echo "Число $value является $verdict"
```

Результаты:

```text
$ ./check_number.sh 7
Число 7 является положительным

$ ./check_number.sh -5
Число -5 является отрицательным

$ ./check_number.sh 0
Число 0 является нулём

$ ./check_number.sh -2.5
Число -2.5 является отрицательным
```

Обработка ошибок:

```text
$ ./check_number.sh
Использование: ./check_number.sh <число>

$ ./check_number.sh abc
Ошибка: 'abc' не является числом.
```

## Задание 4. Список файлов (7 баллов)

Скрипт принимает путь к каталогу, проверяет его и выводит `.txt`-файлы
с размерами.

```bash
#!/bin/bash
# Проверочная работа по Bash — задание 4.
# Выводит .txt-файлы каталога и их размеры.

if [ -z "$1" ]; then
    echo "Использование: $0 <путь к каталогу>" >&2
    exit 1
fi

directory="$1"

if [ ! -e "$directory" ]; then
    echo "Ошибка: '$directory' не существует." >&2
    exit 1
fi

if [ ! -d "$directory" ]; then
    echo "Ошибка: '$directory' — это файл, а не каталог." >&2
    exit 1
fi

echo "Найдены .txt файлы в $directory:"

found=0
while IFS= read -r file; do
    size=$(du -h "$file" | cut -f1)
    echo "- $(basename "$file") ($size)"
    found=$((found + 1))
done < <(find "$directory" -maxdepth 1 -type f -name "*.txt" | sort)

if (( found == 0 )); then
    echo "  (файлов с расширением .txt нет)"
else
    echo "Всего файлов: $found"
fi
```

Результат:

```text
$ ./list_files.sh ~/Documents
Найдены .txt файлы в /home/student/Documents:
- notes.txt (4.0K)
- readme.txt (1.0K)
Всего файлов: 2
```

Обработка ошибок:

```text
$ ./list_files.sh /nonexistent
Ошибка: '/nonexistent' не существует.

$ ./list_files.sh ~/Documents/readme.txt
Ошибка: '/home/student/Documents/readme.txt' — это файл, а не каталог.
```

Цикл `while ... done < <(find ...)` безопасно обрабатывает имена
с пробелами: `IFS= read -r` читает строку целиком. `-maxdepth 1`
ограничивает поиск текущим каталогом, `-type f` исключает подкаталоги.
