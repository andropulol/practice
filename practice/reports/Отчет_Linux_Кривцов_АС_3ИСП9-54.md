## Часть 1. Работа с файлами и директориями

### Задание 1.1. Навигация и создание структуры

```text
$ pwd
/home/student
$ ls ~
Desktop  Documents  Downloads
$ mkdir ~/linux_practice
$ cd ~/linux_practice
$ pwd
/home/student/linux_practice
$ mkdir documents projects downloads
$ ls
documents  downloads  projects
```

**Ответ на вопрос.** Тильда `~` — сокращение для домашнего каталога
текущего пользователя. В Linux это обычно `/home/<имя>`, у суперпользователя —
`/root`. Поэтому `ls ~` и `ls /home/student` дают одинаковый результат.

### Задание 1.2. Создание и работа с файлами

```text
$ echo "Моя первая практическая работа" > readme.txt
$ cat readme.txt
Моя первая практическая работа
$ echo "Дата выполнения: $(date)" >> readme.txt
$ cat readme.txt
Моя первая практическая работа
Дата выполнения: Вт 18 ноя 2026 10:42:17 MSK
```

Файл `numbers.txt` создаётся циклом:

```text
$ for i in {1..10}; do echo "Число $i" >> numbers.txt; done
$ cat numbers.txt
Число 1
Число 2
...
Число 10
```

**Ответ на вопрос.** `>` перенаправляет вывод в файл и **перезаписывает**
его: старое содержимое уничтожается, при отсутствии файла он создаётся.
`>>` **дописывает** вывод в конец файла, сохраняя прежние строки.
Если нужен журнал или накопление данных, используется `>>`; если файл
формируется заново — `>`.

### Задание 1.3. Копирование и перемещение

```text
$ cp readme.txt documents/
$ ls documents/
readme.txt
$ mv numbers.txt downloads/
$ ls downloads/
numbers.txt
$ ls
documents  downloads  projects  readme.txt
$ cp -r documents projects/
$ ls projects/
documents
```

После `mv` файла `numbers.txt` в текущем каталоге уже нет — команда
перемещает, а не копирует.

**Ответ на вопрос.** Опция `-r` (recursive) нужна для **рекурсивного**
копирования каталогов: без неё `cp` откажется копировать папку и выведет
`omitting directory`. С `-r` копируются сам каталог, все вложенные
подкаталоги и файлы.

## Часть 2. Поиск и фильтрация

### Задание 2.1. Поиск файлов

```text
$ touch file1.txt file2.log file3.txt document.pdf image.jpg
$ find . -name "*.txt"
./file1.txt
./file3.txt
./readme.txt
./documents/readme.txt
./projects/documents/readme.txt
$ find . -name "file*"
./file1.txt
./file2.log
./file3.txt
$ find ~/linux_practice -size +1k -type f
    (пусто: все созданные файлы меньше 1 КБ)
$ find ~/linux_practice -mmin -10
.
./file1.txt
./file2.log
```

`find` обходит дерево каталогов и проверяет каждый объект по условию:
`-name` — по имени, `-size` — по размеру, `-mmin` — по времени изменения.

### Задание 2.2. Поиск текста (grep)

Файл `data.txt`:

```text
Иванов Иван 25
Петров Петр 30
Сидоров Сидор 28
Иванова Мария 22
Петрова Анна 35
```

```text
$ grep "Петров" data.txt
Петров Петр 30
Петрова Анна 35

$ grep -E "[3-9][0-9]" data.txt
Петров Петр 30
Петрова Анна 35

$ grep -v "Иван" data.txt
Петров Петр 30
Сидоров Сидор 28
Петрова Анна 35

$ grep -c "Иванов" data.txt
2
```

Счётчик равен 2, потому что шаблон `Иванов` входит и в `Иванов`,
и в `Иванова`.

**Ответ на вопрос.** Опция `-v` (invert match) инвертирует условие:
`grep` выводит строки, которые **не содержат** указанный шаблон.
Это удобно для отбрасывания служебных строк, комментариев и заголовков.

### Задание 2.3. Комбинирование команд (конвейеры)

```text
$ head -5 data.txt
Иванов Иван 25
Петров Петр 30
Сидоров Сидор 28
Иванова Мария 22
Петрова Анна 35
$ tail -3 data.txt
Сидоров Сидор 28
Иванова Мария 22
Петрова Анна 35
$ awk '{print $1}' data.txt | sort | uniq
Иванов
Иванова
Петров
Петрова
Сидоров
$ awk '{print $1}' data.txt | sort | uniq -c
      1 Иванов
      1 Иванова
      1 Петров
      1 Петрова
      1 Сидоров
```

**Ответ на вопрос.** Символ `|` (pipe) соединяет команды: стандартный
вывод левой команды становится стандартным вводом правой. Данные
передаются потоком, без промежуточных файлов. Конвейер можно строить
из любого числа звеньев: `awk` выделяет фамилию, `sort` сортирует,
`uniq -c` считает повторы.

## Часть 3. Права доступа

### Задание 3.1. Изменение прав

```text
$ ls -l script.sh
-rw-r--r-- 1 student student 39 ноя 18 11:05 script.sh

$ chmod +x script.sh
$ ls -l script.sh
-rwxr-xr-x 1 student student 39 ноя 18 11:05 script.sh

$ ./script.sh
Hello, World!
Вт 18 ноя 2026 11:06:02 MSK

$ chmod -r script.sh
$ ls -l script.sh
--wx--x--x 1 student student 39 ноя 18 11:05 script.sh

$ cat script.sh
cat: script.sh: Permission denied

$ chmod 644 script.sh
$ ls -l script.sh
-rw-r--r-- 1 student student 39 ноя 18 11:05 script.sh
```

После `chmod -r` снимается право на чтение у владельца, группы и остальных,
поэтому `cat` не может открыть файл. Если команды выполняются от `root`,
ограничение не сработает: суперпользователь игнорирует права доступа.

**Ответ на вопрос.** Запись `644` — восьмеричная маска из трёх цифр:

| Цифра | Кто | Значение | Права |
|---|---|---|---|
| 6 | владелец | 4 + 2 | чтение и запись (`rw-`) |
| 4 | группа | 4 | только чтение (`r--`) |
| 4 | остальные | 4 | только чтение (`r--`) |

Итого `-rw-r--r--`: файл можно читать всем, изменять — только владельцу,
запускать — никто не может. Для скриптов обычно используют `755`
(`-rwxr-xr-x`).

$ nslookup google.com

  % Total    % Received % Xferd  Average Speed

кэширования и сервер. Это удобно для проверки доступности URL и настройки
редиректов, не скачивая страницу целиком.

## Контрольные вопросы

1. **Какая команда показывает содержимое текущей директории?**
   `ls`; подробный список с правами, владельцем и размером — `ls -la`.

2. **Как создать новую директорию?**
   `mkdir имя`; вместе с недостающими родительскими каталогами —
   `mkdir -p путь/к/каталогу`.

3. **Как скопировать файл с сохранением прав?**
   `cp -p файл копия` — сохраняются права, владелец (если позволяет),
   время изменения. Для каталогов с полным сохранением атрибутов
   используется `cp -a`.

4. **Чем отличается `>` от `>>`?**
   `>` перезаписывает файл, `>>` дописывает данные в конец.

5. **Как найти все файлы с расширением `.txt`?**
   `find . -name "*.txt"`; с фильтром только файлов —
   `find . -type f -name "*.txt"`.

6. **Как сделать файл исполняемым?**
   `chmod +x файл` (или точнее `chmod 755 файл`), затем запуск `./файл`.

7. **Как посмотреть IP-адрес компьютера?**
   `ip addr` (IPv4-адреса: `ip -4 addr`), кратко — `hostname -I`.

8. **Что делает команда `grep`?**
   Ищет в файлах или потоке строки, соответствующие шаблону, и выводит
   их. Поддерживает регулярные выражения (`-E`), инверсию (`-v`),
   подсчёт (`-c`), рекурсивный поиск (`-r`).

### Задание 2. Пять самых больших `.log`-файлов

```bash
find /var/log -type f -name "*.log" -printf '%s %p\n' \
    | sort -nr | head -5
```

`find` находит файлы и печатает размер в байтах вместе с путём,
`sort -nr` сортирует по убыванию, `head -5` оставляет пять строк.
Переносимый вариант без `-printf`:

```bash
ls -lS $(find /var/log -type f -name "*.log") | head -6
```

Здесь `ls -lS` сортирует список по размеру, `head -6` учитывает строку
`total`. Готовый скрипт — `top_logs.sh`.
