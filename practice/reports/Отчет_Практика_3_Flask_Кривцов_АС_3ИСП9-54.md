## Цель работы

Понять, как Python-код превращается в веб-страницу: маршруты, HTTP-запрос,
ответ браузеру, режим отладки.

## Используемые инструменты

- Python 3.11.9
- Flask 3.1.3 (установлен командой `pip install flask`)
- браузер и встроенный сервер разработки Flask

## Структура проекта

```
python/03_flask_hello/
└── main.py   # приложение с тремя маршрутами
```

## Ход выполнения

1. Установлен Flask, версия проверена через `python -c "import flask"`.
2. Создано приложение `app = Flask(__name__)`.
3. Добавлены маршруты:
   - `/` — HTML-страница с приветствием;
   - `/about` — текст о проекте;
   - `/status` — JSON для проверки состояния.
4. Запуск: `python main.py` (порт 5000, `debug=True`).
5. Проверены все маршруты и ответ 404 на несуществующий адрес.
6. Проверена автоперезагрузка: после правки текста Flask сам перезапустил
   сервер, страница обновилась без ручного старта.

## Ответы на контрольные вопросы

**1. Что делает декоратор `@app.route('/')`?**
Регистрирует функцию как обработчик URL `/`. Flask запоминает пару
«адрес → функция» и вызывает функцию, когда приходит запрос на этот адрес.

**2. Чем `GET` отличается от `POST`? Какой метод используется по умолчанию?**
`GET` предназначен для получения данных, параметры видны в URL, запрос
можно кэшировать и повторять. `POST` передаёт данные в теле запроса и
применяется для изменения состояния. По умолчанию маршрут принимает только
`GET`.

**3. Зачем нужен `debug=True` и почему его нельзя использовать на сервере?**
Он включает автоперезагрузку при изменении кода и подробную страницу ошибок.
На реальном сервере это опасно: отладочная страница раскрывает исходный код,
пути и переменные, а интерактивный отладчик позволяет выполнить произвольный
код.

**4. Что означает адрес `127.0.0.1:5000`?**
`127.0.0.1` — локальный адрес (localhost), то есть этот же компьютер.
`5000` — порт, на котором Flask слушает запросы. С других компьютеров
адрес недоступен.

**5. Почему при открытии `/nonexistent` мы получаем 404, а не ошибку Python?**
Flask не нашёл подходящего маршрута и вернул штатный HTTP-ответ
404 Not Found. Это не исключение в коде, а нормальное поведение роутера.

**6. Почему папка для шаблонов должна называться `templates`?**
Это соглашение Flask по умолчанию: `template_folder='templates'`.
Имя можно изменить, передав параметр в `Flask(__name__, template_folder=...)`,
но по умолчанию используется именно `templates`.

**7. Что произойдёт при запуске двух серверов на одном порту?**
Второй процесс не сможет занять порт и завершится с ошибкой
`Address already in use` (на Windows — `OSError: [WinError 10048]`).
