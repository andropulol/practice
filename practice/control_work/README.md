# Контрольная работа по МДК.09.01

| Файл | Содержимое |
|---|---|
| `answers.md` | ответы на тест (часть A) и задания 11–13 |
| `task11_fixed.py` | исправленный код из задания 11 + самопроверка |
| `task12_delete.py` | функция `delete_task_by_id()` + самопроверка |

## Запуск

```bash
python task11_fixed.py
python task12_delete.py
```

Оба файла создают собственную базу рядом с собой, выполняют проверку
и печатают результат. После запуска остаётся файл `task11.db`
(в `task12_delete.py` база удаляется в конце проверки).
